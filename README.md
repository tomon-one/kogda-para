# WhensClass

Расписание НГОК на домашнем экране телефона. Виджет показывает пары своей
группы на сегодня, переключается на завтра и работает без сети.

Зачем: чтобы узнать аудиторию, приходилось открывать общую Google-таблицу на
187 групп — она грузится около пятнадцати секунд, и в ней ещё надо найти свою
колонку.

## Устройство

- `server/` — служба на Python. Читает таблицу колледжа, разбирает её и отдаёт
  компактный JSON: около 1.7 КБ на три дня вместо 820 КБ.
- `android/` — приложение и виджет (Kotlin, Jetpack Glance).
- `docs/` — [формат таблицы](docs/source-format.md), [контракт API](docs/api.md),
  [развёртывание](docs/deploy.md).
- `tools/` — вспомогательные скрипты: выгрузить лист, собрать фикстуру,
  проверить, не переделали ли таблицу.

## Сервер локально

```bash
cd server
python -m venv .venv
.venv/Scripts/python.exe -m pip install -e ".[dev]"
.venv/Scripts/python.exe -m uvicorn whensclass.main:app --port 8081 --app-dir src
```

Проверка: `curl http://127.0.0.1:8081/v1/schedule/isp-924-2`

Тесты: `.venv/Scripts/python.exe -m pytest tests -q`

## Если расписание перестало обновляться

Первым делом — `GET /v1/meta`. Поле `status`:

- `ok` — данные свежие;
- `stale` — таблицу не удалось прочитать или её формат изменился; отдаётся
  прежний снимок, в журнале службы написана причина;
- 503 — служба ещё ничего не разобрала.

Если колледж переделал таблицу, смотрите [docs/source-format.md](docs/source-format.md):
там записано, как она была устроена. Аварийный путь — прописать нужный лист
руками в `WHENSCLASS_SHEET_TITLE` и перезапустить службу.
