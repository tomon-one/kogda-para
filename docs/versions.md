# Как называются версии

```
pr-Зерно.0.1.0
│  │     │ │ └── мелкий патч: правки вёрстки, текстов, одиночные ошибки
│  │     │ └──── крупный патч: заметные изменения, новые возможности
│  │     └────── крупный релиз: то, ради чего стоит рассказать всем
│  └──────────── имя выпуска
└─────────────── b — бета, pr — пре-релиз, r — релиз
```

Буквы впереди говорят, чего ждать: `b` — приложение ещё меняется и может
сломаться, `pr` — почти готовая версия: раздаётся группе, крупных изменений
больше не будет, только исправления ошибок и небольшие улучшения; `r` —
версия, которую не стыдно раздать кому угодно.

## Имена выпусков

Имя меняется вместе со второй цифрой — крупным патчем. Слова короткие,
в одно-два слога: длинное имя не влезает в строку и не запоминается.

Тема имён меняется с крупным релизом — и со сменой буквы.

**pr, 0.1–0.9 — прорастание. Порядок держит рост: от зерна к плоду**

| | | | |
|---|---|---|---|
| 0.1 Зерно | 0.2 Росток | 0.3 Всход | 0.4 Побег |
| 0.5 Лист | 0.6 Бутон | 0.7 Цвет | 0.8 Завязь |
| 0.9 Плод | | | |

Первая — сборка 1, `pr-Зерно.0.1.0` (27.09.2026), когда приложение готовили к
раздаче группе. По имени видно, сколько до релиза: из «Плода» выходит
`r-Алтай.1.0.0`, а крупных переделок, которым не хватит девяти имён, в
пре-релизе быть не должно.

До 27.09.2026 счёт был другим: бета шла с «призрачными» именами 0.1–0.9 (Дух …
Сон), пре-релиз продолжал её номерами 0.10 и дальше, а сборки дошли до 86-й.
Перед раздачей счёт начат заново — с первой сборки и с 0.1.0: так номер версии
говорит, сколько приложение прошло с первого выпуска для людей.

**1.x — то, что на карте не двигается: реки и горы. С «А» и по алфавиту**

| | | | |
|---|---|---|---|
| 1.0 Алтай | 1.1 Байкал | 1.2 Витим | 1.3 Голец |
| 1.4 Дон | 1.5 Енисей | 1.6 Жигули | 1.7 Зея |
| 1.8 Иртыш | | | |

Одна тема на всю ветку, а не «что-нибудь твёрдое»: иначе в списке заводятся
и минерал, и зверь, и «жгут», а Барс с Ирбисом оказываются одним и тем же
животным под разными словами. Половина имён сибирская — Обь и Иртыш прямо
за окном.

С релиза алфавит соблюдается без пропусков: по имени видно, что новее, как
у выпусков Ubuntu. Первый релиз — `r-Алтай.1.0.0`, его патчи — `r-Алтай.1.0.1`,
`r-Алтай.1.0.2`. Крупный патч меняет имя: `r-Байкал.1.1.0`.

## Номер сборки

Кроме имени есть простой счётчик — `versionCode`. Он растёт на единицу с
каждой выложенной сборкой и никогда не повторяется: по нему приложение
понимает, что на сервере лежит версия новее установленной. Имя для этого не
годится — сравнивать слова машина не умеет. По нему же называется файл на
сервере: в имени версии бывают русские буквы, а адрес с ними не открывается.

## Где менять

`android/app/build.gradle.kts`:

```kotlin
versionCode = 4                  // то, что стояло, плюс один
versionName = "pr-Росток.0.2.0" // по правилам выше
```

Числа здесь для примера: текущие смотрите в самом файле, а не в этом документе —
иначе он устаревает с каждой сборкой.
