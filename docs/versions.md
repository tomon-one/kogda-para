# Как называются версии

Имя версии выглядит так:

```
b-Аксолотль.0.3.0
│ │          │ │ └── мелкий патч: правки вёрстки, текстов, одиночные ошибки
│ │          │ └──── крупный патч: заметные изменения, новые возможности
│ │          └────── крупный релиз: то, ради чего стоит рассказать всем
│ └───────────────── имя выпуска
└─────────────────── b — бета, r — релиз
```

Буква впереди говорит, чего ждать: `b` — приложение ещё меняется и может
сломаться, `r` — версия, которую не стыдно раздать кому угодно.

## Номер сборки

Кроме имени у приложения есть простой счётчик — `versionCode`. Он растёт на
единицу с каждой выложенной сборкой и никогда не повторяется: по нему
приложение понимает, что на сервере лежит версия новее установленной. Имя
версии для этого не годится — сравнивать слова машина не умеет.

## Где менять

`android/app/build.gradle.kts`:

```kotlin
versionCode = 27              // просто следующее число
versionName = "b-Выдра.0.3.0" // по правилам выше
```
